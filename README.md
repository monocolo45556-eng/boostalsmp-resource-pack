# boostalsmp-resource-pack

## BoostalSMP S7 - December Monthly Items

The previous Java v31 / Bedrock v50 bundle is superseded. Java v31 incorrectly
used the supplied Bedrock inventory PNGs as flat Java item textures. Do not
install v31 or its prior Oraxen overlay.

- Java v32: [universal pack](BoostalSMP-S7-December-Universal-v32-Ranks.zip)
- Bedrock v51: [icon pack](BoostalSMP-S7-December-Bedrock-v51-Icons.mcpack)
- Geyser mapping, Oraxen overlay, and build report: [S7-December/](S7-December/)

Java/Oraxen uses the real 3D models, texture atlases and animation metadata
from the Christmas 2025 source archive. The seven supplied item PNGs are used
only as Bedrock inventory icons and are byte-for-byte preserved in v51. No
Bedrock model geometry was added.
